# 全部历史访客地图

地图位于个人资料和社交链接下方：桌面端在左侧栏，窄屏在个人资料区下方。使用 Stats4U 的世界地图，显示累计到访国家/地区，并在有城市定位数据时绘制城市圆点。

公开统计页：<https://www.stats4u.net/live/8711228908>。

## 配置

`_config.yml` 中的 `visitor_map.counter_id` 是公开计数器编号。留空即可关闭地图；不要将私密管理链接或其令牌放入配置、页面或公开仓库。当前计数器的管理入口单独保存在本地 Git 忽略的 `.learnings/stats4u-management.html`。

组件采用服务官方支持的图片嵌入接口；URL 虽以 `.png` 结尾，服务实际返回可缩放的 SVG。关键参数：

- `tage=0`：全部历史，不使用 30 天滚动窗口。官方生成器的“全部”选项默认省略此参数，本站显式写出 0。
- `orte=1`：显示可定位的城市圆点。
- `bg=none`：透明背景。
- `pal=slate` / `pal=carbon`：分别适配主页浅色和深色主题。
- `cl=en`：地图标签使用英文。
- `rl=1`：只刷新图片、不再次计数；仅主题切换后的请求使用，首次访问不带此参数。

`assets/js/visitor-map.js` 根据主页 `data-theme` 选择图片配色，每次页面加载只发起一次计数请求。它等待首次图片请求完成后再处理主题变化，后续切换使用服务官方的 `rl=1` 刷新规则。调整窗口大小只缩放 SVG，不重新请求图片。禁用 JavaScript 时使用 `<noscript>` 图片。

## 数据范围

- “全部历史”从这个 Stats4U 计数器开始收到访问时累计，无法补回安装前的访客。
- 原 MapMyVisitors 组件已移除，不会同时加载两个统计服务。旧统计页 <https://mapmyvisitors.com/web/1c93l> 的测试访问没有导入新计数器。
- 原服务的 `t=tt` 只改变累计访问量文字，未改变地图点集。已通过官方演示站对比验证，因此不能用它实现全部历史城市地图。
- 城市和国家来自 IP 估算；VPN、代理及定位缺失可能使点位不准确或暂时不显示。
- 本地预览会产生测试访问；查验地图颜色或显示数据时，服务图片请求应带 `rl=1`，避免额外计数。服务可能对新数据作缓存或延迟聚合。
- “全部历史”是组件的查询范围，数据保留与服务可用性仍由 Stats4U 管理。

## 验证与维护

修改配置后重启 Jekyll，执行 `bundle exec jekyll build`。检查桌面与窄屏的明暗主题、图片加载、统计页链接，以及主题切换是否只有不计数的刷新请求。地图加载失败时保留替代文字和统计页链接。

官方配置页：<https://www.stats4u.net/maps>。
